# Atribusi foto seed demo

Foto di folder ini dipakai `scripts/seed-demo.mjs` untuk data demo mobile.
Berkas disalin ke `UPLOAD_DIR` dengan nama UUID dan disajikan lewat
`GET /v1/media/:filename`; lisensi juga dicatat di
`vendor_media.license_statement`.
